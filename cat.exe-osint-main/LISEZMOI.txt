CAT.EXE // OSINT · GEOINT TOOL v6.0

PYTHON : 3.14 minimum. LANCER.bat l'installe tout seul s'il manque (winget), sans toucher aux anciennes versions.

LANCEMENT
- Double-clique sur LANCER.bat : installe ce qu'il faut, puis l'outil demarre.
- Version .exe : double-clique une fois sur CREER_EXE.bat -> dossier CatExe-OSINT avec CatExe-OSINT.exe
  (seuls GeoCLIP, la video et l'execution des exercices Python demandent la version LANCER.bat).
- Mac/Linux : python3.14 osint_tool.py

NAVIGATION : fleches haut/bas + Entree. Echap = retour.
PAGES : n (ou fleche droite) = page suivante, p (ou fleche gauche) = page precedente, 1 a 7 = aller a une page.
Le menu principal a une page par categorie, et les longs resultats sont aussi decoupes en pages.
Tape des lettres pour chercher un module (ex. « ip », « deco », « mail »).

CARTES : les pages s'ouvrent via un petit serveur local (http://127.0.0.1) et utilisent des fonds de carte
sans cle (Esri, OpenStreetMap…). Si un fond est bloque, la carte bascule toute seule sur un autre.
